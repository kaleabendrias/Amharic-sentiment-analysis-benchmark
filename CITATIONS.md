# Dataset attribution and references

This project uses the Amharic subset of **AfriSenti**, provided by its original authors. The [pinned upstream README](https://github.com/afrisenti-semeval/afrisent-semeval-2023/blob/5aec3cfcf87b59f885e98641f72e52182776429d/README.md) declares **Creative Commons Attribution 4.0 International** and asks users to cite these four publications:

1. Muhammad et al. (2023). [AfriSenti: A Twitter Sentiment Analysis Benchmark for African Languages](https://aclanthology.org/2023.emnlp-main.862/). EMNLP. DOI: 10.18653/v1/2023.emnlp-main.862.
2. Muhammad et al. (2023). [SemEval-2023 Task 12: Sentiment Analysis for African Languages (AfriSenti-SemEval)](https://aclanthology.org/2023.semeval-1.315/).
3. Muhammad et al. (2022). [NaijaSenti: A Nigerian Twitter Sentiment Corpus for Multilingual Sentiment Analysis](https://aclanthology.org/2022.lrec-1.63/).
4. Yimam et al. (2020). [Exploring Amharic Sentiment Analysis from Social Media Texts: Building Annotation Tools and Classification Models](https://aclanthology.org/2020.coling-main.91/).

Use the publishers' citation downloads for a manuscript's complete BibTeX. The original files downloaded during setup are unmodified. This project adds loading code, source checksums, aggregate integrity reports and an experiment specification; it does not claim authorship of the dataset or its annotations.

License reference: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The dataset's upstream terms do not by themselves select a license for this project's own code; choose a code license before publishing.
